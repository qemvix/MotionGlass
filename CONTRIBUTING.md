# Feedback and contributions

Bug reports and feature suggestions are welcome through [GitHub Issues](https://github.com/qemvix/MotionGlass/issues). Please check existing reports first.

For a useful bug report, include the release version, Windows version, GPU, display resolution/refresh rate, selected mode, and steps to reproduce. State whether turning the effect off resolves the behavior. Remove personal information from screenshots or logs before posting them.

MotionGlass is proprietary. Repository visibility does not grant permission to clone, modify, or redistribute the original code. Before working on or submitting code changes, obtain written permission from qemvix at **electrolighxt@outlook.com**. Applicable law, hosting platform terms, and the [license](LICENSE) still apply.

For authorized development, use .NET 10 on Windows and run `scripts/Test.ps1`. Keep automated checks offscreen. Any live desktop effect test should be an explicit, supervised action with a clear way to turn the effect off.
