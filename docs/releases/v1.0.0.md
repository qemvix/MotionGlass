# MotionGlass 1.0.0

The first portable Windows x64 release of MotionGlass.

## Download

| Asset | What it contains |
| --- | --- |
| **MotionGlass-v1.0.0-win-x64.zip** | Recommended: the app, guides, license, third-party notices, changelog, and offscreen verification results |
| **MotionGlass.exe** | Standalone executable with the .NET runtime included |
| **SHA256SUMS.txt** | SHA-256 checksums for the executable and portable ZIP |
| **LICENSE** | Proprietary license and personal-use permission |

Extract the ZIP and run **MotionGlass.exe**. No installation or administrator access is required. **Blur starts off**, with **Velocity based at 50%** as the first-run selection.

## Included

- Five modes: Velocity based, Frame blending, Hybrid blending, Accumulation max, and Accumulation mix.
- A 0–100% amount control for Velocity and accumulation modes.
- Refresh rate scaling for Velocity based mode.
- Greyed-out controls where a mode uses fixed settings.
- Remembered settings, system tray controls, and display-change handling.
- **Ctrl + Alt + B** to toggle blur; **Ctrl + Alt + Esc** to turn it off.

Closing the app removes the effect and exits. Minimizing keeps the app in the system tray.

## Requirements and known limits

- Windows 10 version 2004/build 19041 or newer, or Windows 11; x64; Direct3D 11; SDR display.
- Intended for normal desktop windows and borderless applications. Protected video, secure desktops, and exclusive fullscreen applications can bypass the overlay. HDR displays are paused.
- Adds latency and GPU load. Initial single-display 1080p observations were around 30–33 FPS in Velocity/Hybrid and 60–65 FPS in temporal modes; results vary.
- Velocity uses estimated screen motion and can produce artifacts. The live cursor stays sharp above its captured trail.
- Multi-monitor and rotated-display paths are implemented but not hardware-verified.
- The executable is unsigned.

The portable binary passes offscreen checks for static-image preservation in all modes, distinct moving-image output, and unmodified pixels at 0% in adjustable modes. Automated checks do not enable desktop blur.
